# PROCEDURE
**STEP 1:** Open the Packet Tracer software.

**STEP 2:** Drag two 2900 switches, two Cisco 1800 routers, and four PC terminals from the toolbar and place them in the workspace.

**STEP 3:** Connect all PC terminals and routers through the switches as shown in the network diagram using CAT 6 patch cables.

**STEP 4:** Configure the IP address and default gateway on all PC terminals.

**STEP 5:** Configure the Delhi router's IP address, save the configuration, and restart the Delhi router.

**STEP 6:** Configure the Chennai router's IP address, save the configuration, and restart the Chennai router.

**STEP 7:** Check the connectivity between the computers in the network.

**STEP 8:** Configure OSPF on the Delhi router, save the configuration, and restart the Delhi router.

**STEP 9:** Configure OSPF on the Chennai router, save the configuration, and restart the Chennai router.

**STEP 10:** Verify connectivity between PC terminals in different networks using the **Ping** command.

**STEP 11:** Check the routing table on the Delhi and Chennai routers using the `show ip route` command.
